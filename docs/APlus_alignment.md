# High-Marks Alignment Control

This is a control checklist, not a grade guarantee.

## Assessment 2
- [ ] Demonstrate progress beyond Assessment One.
- [ ] Critically evaluate limitations/inconsistencies and connect them to the gap.
- [ ] Refine RQs precisely.
- [ ] Justify DSR and mixed methods.
- [ ] Explain software engineering principles in the implementation.
- [ ] Explain ethical and cultural issues and proposed adaptations.

## Assessment 3
- [ ] Final report traces literature → gap → RQs → objectives → design → implementation → evaluation.
- [ ] Critical literature synthesis is updated from Assessments One and Two.
- [ ] Software engineering principles are analysed, not merely listed.
- [ ] Ethical/cultural analysis is evidence-based and connected to project implications.
- [ ] Final results are reproducible and use actual measurements.
- [ ] Presentation includes diverse formats, architecture, demo, evaluation and ethics/culture.

## Evidence principle
Every major objective must have an artifact, test or analysis result. Every claimed result must have a reproducible source.
