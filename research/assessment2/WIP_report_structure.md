# MSE907 Assessment 2 – WIP Report Structure

Assessment 2 is a Work in Progress report. The official brief requires the report to update research, proposed methodology and preliminary ethical/cultural implications. It assesses LO1–LO4 and asks for progress beyond Assessment One, refined research questions, significance, methodology, software-engineering principles, and ethical/cultural issues.

## Task 1 – Literature Review & Gap Analysis
- Research progress since Assessment One
- New findings from 2025–2026 literature where applicable
- Critical comparison of frameworks
- Limitations/inconsistencies
- Standardization, interoperability, privacy, scalability and evaluation gaps
- How the findings refine the selected research gap

## Task 2 – Project Proposal & Research Design
- Refined RQs
- Significance and industry impact
- DSR justification
- Mixed-methods design
- Technical experiments
- Stakeholder/TAM plan
- Data collection and analysis plan

## Task 3 – Research-Informed Software Engineering Analysis
Discuss how the project applies:
- Object-oriented design
- Layered architecture
- SOLID principles where applicable
- Repository/service pattern
- API design
- Agile/iterative development
- Automated testing
- DevSecOps practices
- Requirements traceability

## Task 4 – Ethical and Cultural Issues
Discuss:
- Pharmaceutical/patient data privacy
- Informed consent for interviews/surveys
- Immutability vs data correction/withdrawal
- Security and misuse
- Bias in stakeholder/user evaluation
- Accessibility and demographic differences
- Cultural contexts and data governance, including appropriate consideration of Māori data governance principles in Aotearoa New Zealand where relevant

## Evidence required
Add screenshots of the working prototype, diagrams, tests and development progress. Do not present proposed features as completed results.
